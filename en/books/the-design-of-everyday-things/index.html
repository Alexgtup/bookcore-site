The Design of Everyday Things

Don Norman · 1988

A foundation for human-centered design focused on affordances, feedback, mappings, constraints and designing for error.

#design#ux#usability
Key ideas ↓Русская версия
In one sentence

Make the right action visible, understandable and recoverable instead of blaming users for predictable confusion.

Why it matters

When people repeatedly make the same mistake, the interface or system may be teaching the wrong action.

Core ideas

What is worth remembering after you close the page

01

Visibility guides action

People should be able to see what actions are possible and what state the system is in.

02

Feedback closes the loop

After an action, the system should make the result clear quickly.

03

Design for error

Good systems prevent common mistakes and make recovery cheap when they still occur.

03
Turn it into action

Three things to test today

  1. 1

    Watch one new user attempt a core task without explanation.

  2. 2

    Add feedback to one action whose result is ambiguous.

  3. 3

    Redesign one common error so it is impossible or easily reversible.
