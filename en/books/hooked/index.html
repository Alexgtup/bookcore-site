Hooked

Nir Eyal · 2014

A behavioral product model built around trigger, action, variable reward and investment loops.

Key ideas ↓Русская версия
In one sentence

Use habit loops only where repeated use genuinely serves the user's own goal.

Why it mattersCore ideasTry it
01
Why it matters

Repeated product use can be designed, but the same mechanics can help users or exploit them depending on the problem being solved.

02
Core ideas

What is worth remembering after you close the page

01

Triggers start behavior

External cues can gradually become internal cues when the product repeatedly solves the same need.

02

Reduce action friction

The easier the next useful step is, the more likely behavior is to occur.

03

Investment can increase value

User effort can make a product more useful later by adding data, skill or personalization.

03
Turn it into action

Three things to test today

  1. 1

    Map the current trigger-to-action loop for one product behavior.

  2. 2

    Remove one unnecessary step before the core value appears.

  3. 3

    Check whether the loop serves the user or merely increases usage.
